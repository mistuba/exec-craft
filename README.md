# 奇幻塔防 · 幽林小径

浏览器本地可玩的固定路线塔防（单关卡试玩版）。逻辑与存档均在**你的设备**上运行，不依赖国外 CDN 或在线数据库。

## 玩法摘要

- 怪物沿固定土路前进，漏掉 **10** 个即失败。
- 在**草地**上建造三种塔（不可建在路上）：强弩塔、寒霜祭坛、奥术余烬。
- 杀怪获得金币；塔可升至 **2 级**或**出售**（约 70% 返还）。
- **localStorage** 保存音效、倍速与通关进度；无战斗中途存档。

## 本地运行

```bash
npm install
npm run dev
```

在浏览器打开终端里显示的地址（默认 `http://127.0.0.1:43127`）。

生产构建：

```bash
npm run build
npm run preview
```

构建产物在 `dist/`，可部署到任意静态网站；游戏仍在玩家浏览器里执行。

## 手机怎么玩？

用手机浏览器访问**同一局域网内**电脑的开发地址，或访问你部署了 `dist` 的 HTTPS 站点。代码在**手机浏览器里本地执行**，和电脑一样；只有下载页面时需要服务器（或本地 `npm run dev`），**不需要**为存档单独搭数据库。

## 技术栈

- Vite + TypeScript + Canvas 2D
- 音效：Web Audio API 合成（无外链音频文件）
- 画面：内置简易像素精灵（草地/土路/塔/怪），`image-rendering: pixelated` 保持清晰块面
- 字体：系统 UI + 等宽数字飘字；界面中文
